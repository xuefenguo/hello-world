# 基于 OpenClaw 的桌面助手方案（支持一键部署 / 离线安装 / 图形化配置）

## 1. 目标定义

构建一个面向企业内网与个人开发者的桌面助手应用，**首发平台为银河麒麟桌面操作系统（类 Ubuntu）**，核心能力：

- **一键部署**：用户下载后可快速完成环境初始化与启动。
- **离线安装**：无外网场景可完成安装、升级与回滚。
- **图形化配置**：通过 GUI 管理模型、插件、索引与服务参数。
- **模型接入能力**：同时支持本地私有化模型与云端大模型接入。
- **聊天界面**：内置多会话聊天、上下文管理与常用操作。

建议将产品拆分为“控制台（GUI）+ 运行时（Runtime）+ 离线资源包（Bundle）”三部分。

## 3. 技术选型建议

### 3.1 首发操作系统与桌面框架

- **首发平台：银河麒麟桌面操作系统（x86_64）**
  - 安装形态优先 `.deb` 与离线安装包（支持 U 盘/内网分发）。
  - 与 Ubuntu 兼容的系统工具链优先（systemd、bash、deb 包管理）。
- **优先推荐桌面框架：Tauri**
  - 安装包小、资源占用低。
  - 后端可用 Rust（适合做本地编排、性能和安全性较好）。
- 备选：Electron
  - 生态成熟、前端同学上手快。
  - 但包体积更大。

### 3.2 本地编排层（Orchestrator）

建议职责：

1. 检测硬件与系统依赖（CPU/GPU、驱动、磁盘空间）。
2. 拉起/停止 OpenClaw 及附属服务。
3. 管理配置文件（读写、版本化、回滚）。
4. 提供统一状态 API 给 GUI。

### 3.3 离线包形式

- **基础离线包**：银河麒麟安装程序 + runtime 依赖 + 默认模型。
- **增量离线包**：新模型、插件、补丁。
- **签名与校验**：每个包附带 SHA256 与签名，安装前本地验证。

### 3.4 模型接入策略（本地私有化 + 云端大模型）

- **本地私有化模型**：支持配置本地模型路径/模型服务地址（如本机推理服务）。
- **云端大模型**：支持主流 OpenAI-Compatible API（Base URL、API Key、模型名）。
- **统一模型网关**：在 Orchestrator 侧抽象统一调用协议，屏蔽本地与云端差异。
- **路由策略**：按任务类型选择模型（例如敏感数据走本地、通用问答走云端）。
- **容错机制**：云端不可用时自动降级到本地模型（可配置开关）。

## 4. 一键部署设计

### 4.1 安装向导流程

1. 欢迎页（版本、许可协议）。
2. 环境检测（系统版本/权限/端口占用）。
3. 选择安装模式（标准/自定义）。
4. 一键安装（显示实时日志）。
5. 完成页（启动、导入配置、打开文档）。

### 4.2 一键部署关键点

- 提供“默认可用”配置模板：安装后直接可聊天与调用基础能力。
- 将失败恢复做成显式按钮：
  - 重试
  - 回滚上一步
  - 导出诊断包
- 端口冲突自动处理：自动探测并建议可用端口。

## 5. 离线安装设计

### 5.1 离线资源打包

建议目录结构：

```text
bundle/
  manifest.json
  runtime/
  models/
  plugins/
  scripts/
  checksums.txt
```

`manifest.json`建议字段（建议新增银河麒麟兼容信息）：

- `bundle_version`
- `openclaw_version`
- `min_os`
- `target_distros[]`（如 `kylin-v10`）
- `architectures[]`（如 `x86_64`）
- `components[]`
- `post_install_scripts[]`

### 5.2 离线安装策略

- 全量安装：首次部署使用。
- 增量升级：通过组件版本对比仅更新变更项。
- 回滚机制：保留最近 1~2 个可恢复快照。

## 6. 图形化配置与聊天界面设计

### 6.1 配置中心模块

- **模型管理**：
  - 本地模型：模型路径、量化级别、上下文长度、并发数。
  - 云端模型：供应商、Base URL、API Key、模型列表、超时与重试。
- **推理参数**：temperature/top_p/max_tokens。
- **插件管理**：启停、权限、版本。
- **连接配置**：代理、证书、API 网关。
- **数据与日志**：日志级别、保留天数、导出。

### 6.2 聊天界面（核心工作台）

- **多会话列表**：支持新建、重命名、归档与删除会话。
- **模型切换器**：每个会话可选择本地模型或云端模型。
- **消息区**：支持 Markdown 渲染、代码高亮、复制与重新生成。
- **上下文控制**：查看上下文长度、手动清理历史、插入系统提示词。
- **快捷操作**：清空会话、导出会话、固定常用提示词模板。

### 6.3 配置体验建议

- 每个高级参数带“推荐值”和“风险提示”。
- 支持“测试配置”按钮：保存前先做连通性与可用性检查（本地模型可用性 / 云端 API 连通性）。
- 提供配置快照：
  - 保存命名快照
  - 一键恢复
  - 对比差异

## 7. 银河麒麟适配要点（优先落地）

### 7.1 安装与服务管理

- 使用 `systemd --user` 或系统级 `systemd service` 管理 OpenClaw Runtime。
- 安装器提供 `install.sh` / `uninstall.sh`，并支持无网环境直接执行。
- 首次启动自动做依赖检查（glibc、libstdc++、GPU 驱动与权限）。

### 7.2 打包与分发

- 首版输出 `.deb` + 离线 bundle 双形态，满足桌面双击安装与命令行部署。
- 内网环境建议提供“单文件离线包 + 校验文件 + 安装说明”三件套。
- 对模型文件采用分卷包，减少内网传输失败概率。

### 7.3 图形化运维增强

- 配置中心新增“银河麒麟诊断”页：系统版本、内核版本、依赖缺失项。
- 一键导出诊断包（日志 + 配置快照 + 系统信息）用于远程排障。

## 8. 开发里程碑（MVP 到可商用）

### M1（2~3 周）：MVP 骨架

- GUI 壳子 + 本地服务控制。
- OpenClaw 启停与日志展示。
- 最小可用配置页面 + 可用聊天界面（单会话先行）。

### M2（3~4 周）：离线能力

- 离线 bundle 格式与安装器。
- 本地模型与云端模型双通道接入。
- 包校验、失败回滚。
- 增量升级基础能力。

### M3（3~4 周）：可运维与可扩展

- 插件管理界面。
- 配置快照与诊断包导出。
- 健康检查、资源监控（CPU/内存/显存）。

### M4（2~3 周）：商用增强

- 权限体系与操作审计。
- 企业内网代理适配。
- 安装器签名与安全加固。

## 9. 风险与应对

- **模型体积大、分发慢**：采用基础模型 + 按需增量模型。
- **多平台兼容复杂**：先聚焦银河麒麟（Linux 发行版）打磨稳定性，再扩展 Ubuntu/统信/Windows。
- **用户环境差异大**：安装前做全面预检并自动生成修复建议。
- **离线升级失败风险**：强制做原子升级与快照回滚。

---

## 10. 你可以马上开始的第一步

1. 首发平台先锁定银河麒麟（建议先做 V10 + x86_64）。
2. 在 OpenClaw 之上实现一个最小 Orchestrator（只做启动、停止、健康检查）。
3. 用 Tauri 先做核心四页 GUI（安装、配置、聊天、状态）。
4. 用 `bundle/manifest.json` 固定离线包格式，先跑通全量离线安装。

当以上打通后，再接入高级配置和插件市场，会更稳。
