## 3. MVP API 合同（建议先固定）

### 3.1 健康检查

- `GET /health`
- 返回示例：

```json
{
  "status": "ok",
  "runtime": "running",
  "version": "0.1.0"
}
```

### 3.2 聊天接口

- `POST /v1/chat/completions`
- 请求关键字段：
  - `provider`: `local` | `cloud`
  - `model`: string
  - `messages`: array
- 返回关键字段：
  - `content`
  - `usage`
  - `latency_ms`

### 3.3 配置测试

- `POST /v1/config/test`
- 入参：provider 相关配置
- 出参：`ok` / `error_message`

## 4. 首个验收标准（DoD）

以下 6 条全部满足即视为 MVP 可验收：

1. 在银河麒麟桌面系统上成功安装并启动。
2. 聊天页面可完成连续 5 轮对话。
3. 可在同一会话中切换“本地模型/云端模型”。
4. 配置页面“测试连接”可正确报告成功或失败。
5. 应用异常退出后，可恢复最近会话记录。
6. 可导出日志用于问题定位。
